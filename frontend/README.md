# Echo frontend

Next.js (App Router) + TypeScript + Tailwind CSS, installable as a PWA.

```bash
npm install
npm run dev        # http://localhost:3000
```

To open it on a phone on the same Wi-Fi network: `npm run dev -- -H 0.0.0.0`, then go to `http://<your-computer-ip>:3000`.
(The microphone needs HTTPS on phones, so recording only works on a phone once the app is deployed or tunnelled.)
